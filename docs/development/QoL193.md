This pass builds on owner-accepted automatic20. It is not public or hardware
accepted yet. It makes five requested changes:

- Deck hints: transparent 320x26 maximum canvas, native CUF font and Valve View
  glyph; left anchor reserves space for the original menu controls. Campaign
  shows the actual Hold View binding. Battle and possession also show Tap View.
  No menu hint and no desktop hints. Native UI scaling is unchanged.
- Possession movement: cardinal-axis tolerance with hysteresis. Diagonal intent
  begins at a minor/major ratio of0.50 and releases below0.35; activation/release
  magnitudes0.18/0.12 after the existing radial deadzone. Deliberate diagonals,
  strafing, held sprint and all native movement speeds remain available.
- Fire-order/aim display: acquire stable status before reading validation time.
  Previously a writer could publish during the HUD's other reads, and the old
  timestamp then rejected the new status as coming from the future. The fixture
  reproduces this case. Future/stale/identity/reset refusal remains unchanged.
  This is a verified race, not proof that every reported visual flicker is gone.
- Battle groups: tap recalls, hold550ms assigns, never recalling before the hold.
  Long holds fire once; release does not recall. Focus/device/context/help loss
  cancels pending gestures. Multi-direction rollover waits for neutral. The
  existing Ctrl+number native shortcut route and L5 chord are retained.
- Battle RT double click: standard DOWN, UP, DOUBLE, UP native window messages.
  Uses system timing and pixel-distance limits. Moving away, dragging, orders,
  reset/focus loss, Ctrl and Shift prevent unintended double-click classification.
  The original native selection handler decides what to focus; no replacement
  camera movement, artificial selection target or new engine hook is added.
